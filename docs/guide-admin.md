# science26 관리자 사용 설명서

학생 프로젝트 배포 플랫폼 **science26** 을 운영하는 선생님·관리자용 안내예요.
서버 설치·점검처럼 서버에 직접 접속해서 하는 일은 맨 아래 **서버 운영** 항목을 보세요.

| 주소 | 하는 일 |
|---|---|
| `https://science26.bssm.dev` | 전시관 |
| `https://science26-upload.bssm.dev` | 대시보드 (로그인 → **관리자** 탭) |

---

## 1. 관리자 권한

- 관리자는 서버 설정 파일(`.env`)의 `ADMIN_EMAILS` 목록으로 정해져요. 추가·삭제는 서버 담당자가 해요
- 학교 계정이 아닌 개인 Gmail 도 이 목록에 있으면 로그인할 수 있어요
- 로그인하면 상단에 **관리자** 탭이 생겨요. 학번이 없는 관리자는 관리자 화면만 보여요

> ⚠️ 관리자 구글 계정은 플랫폼 전체 권한을 가져요. **구글 2단계 인증**을 꼭 켜 주세요.

---

## 2. 학생 등록 (학번 연결)

학번이 연결된 학생만 프로젝트를 올릴 수 있어요.

1. `students.xlsx` 양식에 **email, 학번, 이름** 을 한 줄에 한 명씩 작성
   - email: 학생이 실제로 로그인할 **학교 구글 계정**
   - 학번: 숫자 4자리, 한 학번에 한 계정만
2. **파일 → 다른 이름으로 저장 → `CSV UTF-8(쉼표로 분리)`** (그냥 CSV 는 한글이 깨질 수 있어요)
3. 관리자 탭 → **학번 등록** → CSV 파일 올리기
4. 결과에 "추가 N명, 갱신 N명, 오류 N건" 이 나와요. 오류가 있으면 줄 번호와 이유가 표시돼요

```
email,학번,이름
s1411@bssm.hs.kr,1411,김하린
s1203@bssm.hs.kr,1203,박도윤
```

> 💡 같은 파일을 다시 올려도 돼요. 이미 있는 학생은 이름·학번이 갱신돼요.
>
> 학생 명단은 개인정보예요. 파일을 공유 드라이브나 채팅에 올리지 마세요.

---

### 학생 한 명 추가 · 테스트 계정
관리자 탭 → **학생 한 명 추가** 에서 이메일·학번·이름을 넣어요.
- **테스트 계정** 을 켜면 학교 계정이 아닌 구글 계정(개인 Gmail 등)도 **학생으로** 로그인할 수 있어요. 학생 화면을 직접 써 볼 때 쓰세요
- 테스트 계정 학번은 실제 학생과 겹치지 않게 `9901` 처럼 9로 시작하는 걸 권장해요 (`9999` 는 자동 점검이 쓰니 피하세요)
- 학생 현황에서 **테스트 계정** 묶음으로 따로 보이고, 반 통계에는 들어가지 않아요
- 필요 없으면 학생 현황에서 카드의 🗑 버튼으로 지워요

## 3. 관리자 화면 둘러보기

### 학생 현황
- 등록된 학생 **전원** 기준이라, 아직 안 올린 학생도 보여요
- 학반 버튼: `1학년 4반 10/20` 처럼 반마다 제출 수/전체 수. 다 낸 반은 초록색
- 필터: **미제출**(기본) · 미접속(한 번도 로그인 안 함) · 제출 완료 · 전체, 이름·학번 검색
- **미제출 명단 복사**: 선택한 반의 미제출 학생 `학번 이름` 목록을 복사해요 (단톡방 공지용)
- **엑셀로 받기**: 지금 고른 학반·필터 그대로 xlsx 로 내려받아요 (학년·반·번호·학번·이름·이메일·상태·로그인 여부·프로젝트)
- 학번 4자리는 학년·반·번호로 읽어요 (`1411` → 1학년 4반 11번)
- **평가 메모**: 학생 카드의 ✏️ 버튼으로 메모를 남겨요 (예: `완성도 A, 발표 좋음`). **선생님만 보이고** 학생에게는 안 보여요. 엑셀로 받으면 '메모' 칸에 같이 들어가요
- **계정 삭제**: 학생 카드 오른쪽 🗑 → 확인 창에 학번을 입력해야 지워져요. 계정·프로젝트·배포된 페이지·학생 DB·파일·조회수가 모두 지워지고 되돌릴 수 없어요. 관리자 계정은 지울 수 없어요. 다시 쓰려면 학번을 새로 등록하세요

### 전체 프로젝트
- 상단 숫자: 전체 / 실행 중 / 쉬는 중(30분 미방문으로 잠듦) / 빌드 중 / 실패 / **디스크 사용률**
- 학번·이름·제목으로 검색
- 학생마다 상태, 주소, CPU·메모리·DB 사용량
- 마지막 배포가 실패했으면 빨간 글씨로 이유가 보여요
- 15초마다 자동 새로고침

| 버튼 | 하는 일 |
|---|---|
| **중지** | 학생 프로젝트를 내려요. 학생이 다시 시작할 수 있어요 |
| **삭제** | 스택·DB·파일·기록을 **모두 지워요. 되돌릴 수 없어요** |

### AI 연결 (MCP)
- 학생이 대시보드에서 **AI 연결 토큰**을 만들어 Claude Code·Cursor 에서 바로 배포할 수 있어요 (주소 `https://science26-upload.bssm.dev/api/mcp`)
- 토큰은 그 학생 프로젝트에만 쓸 수 있고, 관리자 기능·다른 학생 프로젝트·계정 정보에는 접근 못 해요. 서버에는 해시만 저장해요
- 30일 만료, 학생당 3개. 학생이 직접 지울 수 있고, 계정을 지우면 토큰도 같이 지워져요
- 업로드는 대시보드와 같은 검사(마감, 용량, 10분에 5번, 디스크 90%)를 거쳐요. 최근 활동·디코 알림에 `AI(MCP)` 로 표시돼요
- 큰 파일은 10분짜리 **1회용 업로드 주소**로 올라와요 (브라우저에서는 못 써요)
- 올린 파일(zip·GitHub 저장소) 안에 살아 있는 토큰이 있으면 배포를 멈추고 **그 토큰을 자동 폐기**해요. 최근 활동에 '토큰 유출 감지·자동 폐기' 로 남아요

### 조회수
- 학생 페이지를 **브라우저로 열 때** 세션 쿠키로 세요. 같은 브라우저는 창을 닫기 전(최대 24시간)까지 프로젝트당 **1번만** 세요
- 새로고침·페이지 안 이동·이미지 같은 요청은 세지 않고, 검색 로봇도 빼요
- 쿠키를 지워 가며 부풀리지 못하게 같은 IP 에서 프로젝트당 시간당 30번까지만 세요
- 전시관 카드 썸네일, 학생 대시보드, 관리자 프로젝트 목록(오늘 조회 포함)에 보여요

### 전시관 정렬·인기 순위
- 전시관에서 **학번순(기본) · 인기순 · 조회수순 · 최신순** 정렬, 웹·웹앱·앱 분류, 학반 필터를 쓸 수 있어요
- 인기 점수가 가장 높은 3개 카드에 **인기 1~3위** 배지가 붙어요
- 인기 점수 = Σ (d일 전 방문자 × 0.8ᵈ, 최근 14일) + 3 × log₂(1 + 누적 조회수)
  - 오늘 방문은 1배, 하루 지날 때마다 20%씩 덜 쳐요 (일주일 전 ≈ 0.2배). 요즘 많이 보는 프로젝트가 위로 와요
  - 누적 조회수는 로그로 조금만 더해서, 처음에 몰린 조회수만으로 1등을 계속 지키지 못해요

### 최근 활동
- 오늘의 **첫 접속 / 프로젝트 등록 / 업로드 / 정보 수정** 수
- 필터: 전체 · 접속 · 프로젝트 · 관리자
- 한 페이지에 20개, 아래에서 페이지 이동
- 첫 페이지를 보고 있으면 20초마다 자동 새로고침

### 운영 설정

| 항목 | 설명 |
|---|---|
| 학생 공지 | 학생 대시보드 맨 위에 뜨는 공지 (300자까지). 비우면 안 보여요 |
| 업로드 마감 | 마감 2주 전부터 학생 대시보드에 남은 시간이 떠요 (하루 남으면 주황색). 예: `2026-12-01 18:00`. 지나면 학생은 **올리기·삭제 불가** (관리자는 가능). 비우면 마감 없음 |
| 서비스당 메모리 (MB) | 풀스택 서비스 하나의 메모리 한도 |
| 스택 합계 (MB) | 한 학생 프로젝트 전체 메모리 한도 |
| CPU | 서비스당 CPU 개수 (0.5 = 반 개) |
| 프로세스 수 | 서비스당 최대 프로세스 수 |

> 💡 리소스 한도는 **다음 배포부터** 적용돼요. 이미 떠 있는 프로젝트는 그대로예요.
>
> 이미 떠 있는 프로젝트에 바로 적용하려면 전체 프로젝트 카드의 **전체 재배포** 를 누르세요. 빌드 없이 지금 버전을 하나씩 다시 띄워요 (서버 재시작으로는 적용되지 않아요).

## 4. 디스코드 알림

### 멘션 알림 (활동)
| 언제 | 예시 |
|---|---|
| 계정 첫 접속 | `첫 접속: 박도윤 (1203)` |
| 프로젝트 등록 (첫 업로드) | `프로젝트 등록: 박도윤 (1203)` + 타입·제목·주소 |
| 새 버전 업로드 | `새 버전 업로드 (v3): ...` |
| 프로젝트 정보 수정 | 바뀐 항목 (제목·링크 이름·썸네일·공개 여부). 같은 학생은 **10분에 한 번만** |
| 프로젝트 삭제 | `프로젝트 삭제: ...` |

### 장애 알림 (멘션 없음, 2분마다 점검)
| 언제 | 반복 |
|---|---|
| 서버 디스크 80% 이상 (90%면 업로드 중단) | 6시간에 한 번 |
| 학생 DB 500MB 넘음 | 학생별 하루 한 번 |
| 학생 DB 1GB 넘어 **접속 차단** / 줄어서 다시 열림 | 바뀔 때 한 번 |
| 실행 중이어야 할 학생 컨테이너가 죽음 | 컨테이너별 1시간에 한 번 |

> ⚠️ 서버 자체가 꺼지면 알림도 못 보내요. 외부 감시 서비스(UptimeRobot 등)로 따로 확인해요.

## 5. 자주 하는 일

### 학생이 "로그인이 안 돼요"
- 학교 구글 계정으로 들어왔는지 확인 (개인 Gmail 불가)
- "학번 등록을 기다리고 있어요" → 그 이메일로 학번 등록 (2번)
- 이메일 오타 → CSV 고쳐서 다시 올리기

### 학생이 "배포가 실패해요"
- 학생 대시보드 **배포 기록** 에 실패 이유와 빌드 로그가 있어요. 관리자 화면 프로젝트 목록에도 빨간 글씨로 보여요
- 흔한 원인: 금지 키(`ports` 등), `localhost` 에만 열기, `/` 로 시작하는 경로
- 학생 설명서와 대시보드의 **AI로 배포 준비하기** 를 안내해 주세요

### 부적절한 프로젝트
1. 관리자 화면에서 **중지** (바로 내려가요)
2. 필요하면 **삭제**
3. 최근 활동에서 누가 언제 올렸는지 확인할 수 있어요

### DB 용량 초과로 학생 앱이 멈춤
- 1GB 를 넘으면 그 학생 DB 접속이 막혀요. 학생이 데이터를 줄이려면 서버 담당자가 정리해야 해요
- 한도 아래로 내려가면 자동으로 다시 열려요

### 평가 날
- 운영 설정에서 **업로드 마감** 을 정해 두면 평가 중에 프로젝트가 바뀌거나 지워지지 않아요
- 학생이 많이 접속하면 서버 사양을 잠시 올리는 걸 서버 담당자와 상의하세요
